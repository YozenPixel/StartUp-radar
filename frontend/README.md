# StartupRadar Frontend (Vite + React 19 + TypeScript)

Application SPA moderne et réactive construite avec :
- **Vite 6** pour un tooling ultra-rapide et HMR instantané
- **React 19** & **TypeScript**
- **Tailwind CSS v4** & **shadcn/ui**
- **Phosphor Icons**

## Démarrage

```bash
# Lancer le serveur de développement local sur http://localhost:3000
npm run dev

# Compiler pour la production
npm run build

# Prévisualiser le build de production
npm run preview
```
